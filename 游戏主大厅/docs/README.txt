《深海捕鱼》YY9 独立游戏包
版本：1.0.0
游戏ID：yy9-deep-sea-fishing
所属：捕鱼厅（fishing-hall）
方向：responsive（横屏 + 竖屏两套响应式排版）
运行主文件：压缩包根目录 index.html
本地完整试玩：Node.js >=18，执行 npm start，然后访问 http://127.0.0.1:4173/

一、交付内容
1. 完整 Canvas2D 捕鱼运行逻辑：鱼群、炮台、炮弹、碰撞、锁定、自动射击、炮值切换、鱼潮、环形鱼阵、黄金鲨王。
2. DEMO 服务端权威资金逻辑：余额、发炮扣款、命中结果、返奖、返水、流水、幂等、防重复结算。
3. PRODUCTION 平台桥接层：正式接口缺失或失败时不会自动切换本地随机结果。
4. 横屏/竖屏两套界面排版，包含 Safe Area 处理。
5. 完整中文界面、鱼倍率图鉴、音频系统、网络恢复提示和状态机。
6. 12种原创海洋生物素材、海底背景、游戏卡片及 9 个音频资源。
7. API、坐标、按钮热区、素材、音频、动画、模式隔离、验收文档。

二、关键玩法
- 点击或按住海面发炮；自动模式按当前瞄准方向连续发炮。
- 锁定模式开启后点击目标鱼，可持续跟随目标。
- 炮值：1 / 2 / 5 / 10 / 20 / 50 / 100 / 200 / 500 / 1000。
- 炮弹允许边缘反弹 2 次，最多存活 4.3 秒。
- 普通鱼群持续游动；红利事件循环：左右鱼潮 → 环形鱼潮 → 黄金鲨王。
- 首次红利事件约 20 秒后出现，之后默认每 75 秒一轮。
- DEMO 的捕获与返奖由 demo-server.mjs 决定，前端不能自行生成资金结果。

三、性能结构
- requestAnimationFrame + delta time；未设置 30/40/50/60 FPS 人工帧率锁。
- 60Hz 设备按浏览器刷新率运行；120Hz 设备可跟随 120Hz 刷新。
- Canvas 单画布渲染，DPR 默认上限 1.75，防止高分辨率设备过度填充。
- 鱼碰撞使用空间网格，避免每帧对所有鱼与所有炮弹做全量组合碰撞。
- 鱼、炮弹、粒子均设总量上限；粒子采用短生命周期；退出时清理 rAF、实时连接和音频。
- 游戏逻辑按 delta time 推进，不会因为屏幕刷新率变高而让鱼速/炮速翻倍。

四、模式
DEMO：本包 Node 服务提供试玩资金、开奖结果和流水。
PRODUCTION：必须由 window.YY9_PLATFORM_CONFIG 映射正式平台接口。正式接口缺失时直接报错并停止进入正式资金流程；不会偷偷降级 DEMO。

五、重要说明
- 当前包已经完成本地 DEMO API 级验证；正式平台登录、真实钱包、正式结算、生产实时服务必须由仓库管理员按《API接口说明.txt》映射后联调。
- 真机 120Hz/110FPS 指标需要在目标 iPhone/Android 120Hz 设备与正式浏览器上实测；代码层面不存在固定低帧率定时器。
- 本包中的鱼类概率仅用于 DEMO，不应被复制为正式环境 RTP 参数。
