《状态机说明》
通用状态：INIT / LOADING / READY / PLAYING / RESOLVING / BONUS / PAUSED / RECONNECTING / ERROR
实现：core/state-machine.js

主要切换：
INIT -> LOADING -> READY -> PLAYING
PLAYING -> BONUS -> PLAYING
PLAYING/BONUS -> PAUSED -> PLAYING
PLAYING/BONUS -> RECONNECTING -> PLAYING
INIT/LOADING/READY/PLAYING/RECONNECTING -> ERROR（按许可路径）
ERROR -> LOADING 或 RECONNECTING

资金逻辑不依赖单一 isPlaying 布尔值。网络中断时进入 RECONNECTING 并停止本地资金结果推演。
